# QHub


📚 Arabic & Qur’an Learning Hub

Description:
A centralized system to manage Arabic learning and Qur’an memorization projects, including interactive tools, organized resources, and exercises to help learners track progress and improve.

🌟 Overview

This repository serves as a central hub for learners who want to:

Learn Arabic grammar, vocabulary, and pronunciation.

Memorize the Qur’an efficiently.

Track progress using exercises and interactive tools.

Access organized resources for easy and structured learning.

All materials are categorized into separate folders for clarity and accessibility.

🗂 Repository Structure
/ArabicGrammar        # Grammar lessons, notes, and exercises
/QuranMemorization     # Qur’an texts, memorization plans, and tracking
/Tajweed              # Pronunciation rules, audio examples, and guides
/Exercises            # Practice exercises, quizzes, and worksheets
/AudioResources       # Recitations, lessons, and pronunciation guides
/Flashcards           # Vocabulary and key concepts for memorization
/Notes                # Miscellaneous notes, tips, and references


Each folder can contain multiple subfolders or files to keep resources organized and easy to navigate.

🚀 Getting Started

Clone the repository

git clone https://github.com/farhadalam75/QHub.git


Explore folders according to your learning goals.

Use resources for studying, practicing, and memorizing.

Track your progress by adding notes or marking completed exercises.

Start with basic Arabic grammar before tackling Qur’an memorization.

Use audio resources to practice Tajweed and pronunciation.

Review exercises frequently to reinforce learning.
